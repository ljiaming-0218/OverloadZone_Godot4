# 马嘉祺大战我哥哥丁程鑫 · STAGE / DUEL

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ljiaming-0218/OverloadZone_Godot4)

真人风大头表情包同人舞台幻想对决。操作马嘉祺，在舞台机关与音符弹幕中成长，挑战丁程鑫的三幕 Boss。角色头像是 AI 生成的真人风夸张表情拼贴，搭配迷你舞台身体；不是本人实拍照片，游戏没有使用歌曲录音或真人声音。

## 浏览器 / 手机运行

```sh
python3 -m http.server 8000 --directory web
```

也可直接打开 `web/index.html`。电脑 WASD / 方向键移动、Space 冲刺吸弹、Q 全场共鸣、E 领取附近补给、Esc 暂停和查看构筑手册、1/2/3 选升级。手机用左摇杆移动，右侧冲刺 / 共鸣，靠近补给后出现领取按钮。自动瞄准射击，电脑可按住鼠标手动瞄准。

目标战斗时长约 **12–15 分钟**，升级与暂停不计时。生命耗尽会提前谢幕。首次点击开始解锁音效；顶部可静音。

## 这次扩展

- 三幕长局：开场交锋 → 追光竞演 → 压轴对决。第 3 / 7 / 12 分钟安排三场 Boss，前一场结束才会安排下一场，前两场获胜不会结束游戏。15 分钟还未完成压轴则失败。
- 每场 Boss 有三个生命阶段，使用旋转音符、扇形追击、落点共振与追光封锁；危险区先预警后生效，冲刺可规避。
- 追击、远程、重装、预警冲锋、指挥机关五类常规敌人及精英变体。敌人生命随时间增长；每 75 秒出现特别波次，每 55 秒尝试安排精英。
- 16 种限级技能、4 套组合进化、2 次初始重选。组合进化在达到配方时自动解锁，可在暂停手册中查看进度。
- 每 90 秒安排一份应援补给，停留 50 秒，需靠近领取；补给三选一。前两场 Boss 后选择永久舞台遗物。
- 巡演 / 压轴两档：压轴敌人生命与受击伤害为巡演的 1.3 倍、敌人移速 1.12 倍、刷新更快。
- 新 Q 版角色与舞台素材、音符弹幕，保留吸弹超频、护盾和共鸣清场。最佳时间、击破与通关次数仅保存在当前浏览器。

玩法结构参考《吸血鬼幸存者》的成长与组合进化、《挺进地牢》的预警和弹幕走位，未复制其代码、美术或音频。机制与调参详见 [GAMEPLAY.md](GAMEPLAY.md)。

## Render 发布

点击上方一键部署按钮，登录 Render、授权仓库并确认创建。`render.yaml` 自动发布 `web/`，不需要 Node 构建、后端、数据库或密钥。已有此仓库自动部署服务时，推送到部署分支后可由 Render 自动更新。平台当前套餐及实际部署状态以 Render 控制台为准。见 [DEPLOY_RENDER.md](DEPLOY_RENDER.md)。

## 验证与范围

`node --test tests/game.test.cjs` 运行机制测试，覆盖演化、Boss 时序、补给、预警与连续十二分钟模拟。模拟使用测试用无敌状态与指定 Boss 击破，验证程序流程，不能证明实际难度已平衡。真机手感、帧率与音效需在 iPhone Safari / Android Chrome 上继续试玩。

浏览器版和 Godot 原型是两套实现。本次主题与长局内容在 `web/`；Godot 工程仍为原先的三分钟原型，未自动同步。Godot 4.6.3 下的原解析错误已修复。
