# 零域超载 · OVERLOAD ZERO

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ljiaming-0218/OverloadZone_Godot4)

高科技轨道反应堆中的弹幕生存游戏。驾驶动力装甲，冲刺吸收敌方能量、发动超载脉冲，利用掩护破口、蓄力打断与机群站位完成三阶段核心攻坚。直接战斗，无情景剧和对白。

首页「更换头像」支持 JPG / PNG / WebP，单文件不超过 5 MB。驾驶员和主核均可使用自选照片或默认装甲。照片仅保存在当前浏览器；兼容之前同站点保存的照片，不上传、不跨设备同步。

## 浏览器 / 手机运行

```sh
python3 -m http.server 8000 --directory web
```

访问 `http://localhost:8000`，也可直接打开 `web/index.html`。电脑 WASD / 方向键移动、Space 冲刺吸弹、Q 超载脉冲、E 领取附近补给、Esc 暂停 / 构筑手册、1/2/3 选升级。手机左摇杆移动，右侧冲刺 / 超载，支持多指同时触控与横竖屏。默认自动瞄准，电脑可按住鼠标手动瞄准。

成功通关约 **12–15 分钟战斗计时**，升级、模块选择和暂停不计时；生命耗尽提前失败。素材加载完毕后允许部署，失败可点击重试。首次交互解锁合成音效，顶部可静音。

## 内容

- 12 类机械单元及精英：追猎蜂、双联炮隼、重装甲虫、突刺游隼、中继指挥机、屏障守卫、磁轨狙击机、纳米修复机、折跃母巢、干扰环卫、三联轨道炮、幽影伏击机。
- 保留战术配合：屏障守卫站到后排前方进行方向性掩护；近战两侧包抄；远程保持射程并横移；狙击先预判、最后 0.4 秒锁定；中继机组织最多三名枪手交叉射击；修复、召唤与蓄力攻击可以打断。
- 三关 Boss：第 3 分钟「堡垒守卫 · AEGIS」、第 7 分钟「棱镜裁决 · PRISM」、第 12 分钟「奇点主核 · NEXUS」。每关三个生命阶段，每第四轮蓄力可破招，硬直 / 后摇期间承伤 +25%。15 分钟仍未完成则失败。
- 18 种限级技能、6 套组合进化、2 次初始重选。蜂群导弹、低温力场、轨道刃环、电弧连锁、弹射光刃带来不同攻击方式；暂停查看配方和反制说明。
- 无伤歼灭 20 台触发「自律超频」：护盾 +10、能量 +12、移速 +15% 持续 3 秒，奖励冷却 14 秒。生命受伤重置进度，护盾完全挡住不重置。
- 每 75 秒特殊波次、每 55 秒尝试安排精英、每 90 秒补给。前两关胜利直接选择永久核心模块，最终胜利直接结算。「标准行动 / 深渊协议」两档难度。
- 全新反应堆甲板、动力装甲、无人机 / Boss 和等离子特效；界面为深色金属、青色能量与紫色主核。敌方危险预警仍与真实伤害几何对应。

成长与组合进化参考《吸血鬼幸存者》，弹幕与预警参考《挺进地牢》，未复制其代码、美术或音频。机制参数见 [GAMEPLAY.md](GAMEPLAY.md)。

## Render 发布

点击一键部署按钮，登录 Render、授权仓库并创建。`render.yaml` 发布 `web/`，无需 Node 构建、后端、数据库或密钥。已有服务若开启部署分支自动部署，推送可触发更新；实际结果以 Render 控制台为准。见 [DEPLOY_RENDER.md](DEPLOY_RENDER.md)。

## 验证与范围

`node --test tests/game.test.cjs` 包含 53 项机制测试，覆盖掩护几何、侧翼移动、预判锁定、协同射击、治疗 / 召唤 / Boss 打断、低温与光刃、组合进化、无伤奖励和连续十二分钟流程。长局模拟使用无敌与指定 Boss 击破，不能证明真实难度已平衡。

Chromium 检查覆盖桌面 1440×1000、手机 390×844 / 844×390、首页与全部菜单主题、头像导入 / 保存 / 恢复默认、多指操作、实际冲刺打断、直接开战 / 模块 / 胜利流程与素材加载。iPhone Safari / Android Chrome 真机帧率、发热和手感仍需实测。

浏览器版和 Godot 原型是两套实现。本次科技视觉与长局内容在 `web/`；Godot 工程仍是原三分钟原型，未自动同步。Godot 4.6.3 下的原解析错误已修复。
