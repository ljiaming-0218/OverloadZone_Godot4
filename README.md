# 下班大作战 · CLOCK OUT CHAOS

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ljiaming-0218/OverloadZone_Godot4)

17:59，办公用品突然活了。上传自己的头像，冲进弹幕积攒怒气，掀桌打穿加班怪，争取准点下班。原创荒诞办公室题材，纸片拼贴怪物、办公室情景剧与长局成长结合。

首页「更换头像」支持 JPG / PNG / WebP，单文件不超过 5 MB。可以更换自己和头目的头像，也可以使用默认纸片 / 怪物。照片仅存当前浏览器，不上传服务器。旧版在同一站点保存的头像继续兼容；照片不跨设备同步。

## 浏览器 / 手机运行

```sh
python3 -m http.server 8000 --directory web
```

访问 `http://localhost:8000`，也可直接打开 `web/index.html`。电脑 WASD / 方向键移动、Space 冲刺吸弹、Q 掀桌爆发、E 领取附近补给、Esc 暂停与查看构筑手册、1/2/3 选升级。手机左摇杆移动、右侧冲刺 / 掀桌，支持同时触控与横竖屏。默认自动瞄准，电脑可按住鼠标手动瞄准。

成功通关目标为 **12–15 分钟战斗计时**，对白、升级和暂停不计时；生命耗尽会提前失败。首次点击开始解锁合成音效，顶部可静音。

## 内容

- 12 类常规怪物及精英：尖叫鼠标、鸭嘴喇叭、鸡脚订书机、滑铲办公椅、会议乌鸦、甩锅锅盖、已读摄像头、鸡汤饮水机、加戏复印机、追命闹钟、连环催稿机、假装下班箱。保留挡弹、预瞄狙击、治疗、召唤等配合机制。
- 新怪招式：闹钟预警后连续发三圈减速弹；催稿机锁定方向后三连急件扇射；纸箱假装撤退并留下陷阱，随后预警反冲。外形离谱，攻击有明确预警和躲避机会。
- 三关 Boss：第 3 分钟「组长 · 五分钟小会」、第 7 分钟「总监 · 最后改一版」、第 12 分钟「老板 · 无限画大饼」。每个 Boss 有三阶段、通用弹幕与独有招式：召集开会、需求回滚、画饼环形封锁。15 分钟仍未完成则失败。
- 18 种限级技能、6 套组合进化、2 次初始重选。键盘连敲、甩锅接力、旋转工牌、冰美式领域和离职纸飞机带来不同攻击方式；暂停查看配方与进度。
- 无伤处理 20 个敌人可领取「带薪摸鱼」：护盾 +10、怒气 +12，移速 +15% 持续 3 秒，奖励冷却 14 秒。真实生命受伤会重置进度，护盾挡住的伤害不会。
- 每 75 秒特殊波次、每 55 秒尝试安排精英、每 90 秒出现可领取补给；前两场 Boss 后选择永久遗物。「准点下班 / 地狱加班」两档难度。
- 7 段原创文字小剧场，开场选择影响初始状态。可逐句、跳过；首页预览不发放奖励。照片、记录仅保存在当前浏览器。

成长与组合进化参考《吸血鬼幸存者》，弹幕与预警参考《挺进地牢》，未复制其代码、美术或音频。机制细节见 [GAMEPLAY.md](GAMEPLAY.md)。

## Render 发布

点击上方一键部署按钮，登录 Render、授权仓库并确认创建。`render.yaml` 自动发布 `web/`，不需要 Node 构建、后端、数据库或密钥。已有服务若开启部署分支自动部署，推送后可自动更新；实际部署结果以 Render 控制台为准。见 [DEPLOY_RENDER.md](DEPLOY_RENDER.md)。

## 验证与范围

`node --test tests/game.test.cjs` 包含 41 项机制测试，覆盖三类新怪攻击、无伤奖励、减速与吸弹、环形危险区、Boss 招式、组合进化、对白和连续十二分钟流程。长局模拟使用测试无敌状态与指定 Boss 击破，不能证明真实难度已平衡。

Chromium 检查覆盖桌面、390×844 手机竖屏、844×390 横屏、头像导入 / 保存 / 重置、多指移动与冲刺、剧情暂停与结尾。iPhone Safari / Android Chrome 真机帧率、发热和手感仍需实测。

浏览器版和 Godot 原型是两套实现：本次主题与长局内容在 `web/`；Godot 工程仍为原先的三分钟原型，未自动同步。Godot 4.6.3 下的原解析错误已修复。
