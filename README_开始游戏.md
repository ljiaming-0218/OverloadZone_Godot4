# 过载禁区 OVERLOAD ZONE

## 这是什么

这是一款**可以运行的 Godot 4 动作割草肉鸽原型**，不是游戏概念图，也不是空项目。

**版本：v0.1 vertical slice（3 分钟生存试炼）**。

主机制：敌人的子弹不是只能躲——冲刺穿过敌弹会吸收并增加过载能量；满能量后按 Q 引爆，清场并产生连锁反应。

### 现有内容

- WASD / 方向键移动；**自动锁定最近的怪物开火**，按住鼠标左键可以手动指定射击方向。
- Space：朝移动方向冲刺，无方向输入时朝瞄准方向冲刺；冲刺过程中回收附近的红色敌方子弹。
- Q：过载能量满时释放冲击波，范围伤害并清除敌方弹幕。
- 三类普通敌人（冲锋怪、发射弹幕的射手、耐打的重装怪）和 1 个 2:00 登场的 Boss。
- 经验晶体、升级三选一、14 类强化（叠加生效）。
- 闪电弹射、击杀爆炸、能量回收、环绕刀刃与吸血修复等联动。
- 屏幕震动、短停顿、命中粒子、渐变冲击波、程序生成音效。
- 开始界面、失败 / 胜利结算、重新开始。
- 无第三方插件、无网络请求、无需额外图片或音频素材。

## 最快试玩：无需安装任何软件

**直接双击 `立即试玩_浏览器版.html`**，用 Chrome 或 Edge 打开即可。浏览器版和 Godot 工程是两套实现，核心机制相同；浏览器版已经完成关键流程的自动化验证。建议先用它判断玩法爽不爽，再用 Godot 工程继续做正式作品。

## Godot 4 编辑工程（Windows）

1. 打开 **https://godotengine.org/download/windows/**，下载 **Godot Engine 4.3 或更新的 4.x 标准版（Standard）**。
2. 解压到任意目录（Godot 标准版通常是免安装的可执行程序）。
3. 解压本项目 ZIP 到你想保存的位置，例如 `D:\Games\OverloadZone_Godot4\`。
4. 打开 Godot → **导入（Import）** → 选项目里的 `project.godot` → **导入并编辑**。
5. 在 Godot 编辑器右上角点 **运行项目 ▶**，或者直接按 **F5**。
6. 出现标题页面后点击「开始试炼」。

**提示：** 第一次打开项目时，Godot 会自动生成 `.godot` 缓存文件夹，这是正常的。

## 建议的第一轮体验任务

1. 进入游戏，别只躲弹幕，试着主动朝红色敌弹冲刺。
2. 看到左上方过载槽满了，按 Q，一次性清掉尽可能多的敌人。
3. 吃绿色经验水晶，优先试【死亡爆破】+【死亡电弧】+【击杀充能】。
4. 看看 2:00 后面对大 Boss 时，冲刺和过载的策略有没有变化。
5. 在一局中记录：最爽的一次连锁爆炸是什么时候，以及哪些时刻不好理解 / 不好操作。

## 这不是最终游戏

本版本用于**验证“冲刺吸弹→过载清屏→Build 联动”是否好玩**。没有关卡商店、多地图、解锁树、联网、存档，也没有正式美术素材。当前测试时长为 3 分钟，正式目标可以扩展到每局 8~12 分钟。

## 改数值从哪里开始

`scripts/game.gd` 顶部：

- `TRIAL_SECONDS`：演示局时长规划（本版 BOSS 固定 120 秒登场；该常量还未接入倒计时结算）。
- `_spawn_enemy()`：敌人 HP、速度、半径。
- `_update_spawns()`：刷怪频率、怪潮成长、BOSS 登场时间。
- `_shoot()`：子弹伤害、子弹数量、射速。
- `_start_dash()`：冲刺速度与冷却。
- `_absorb()`：每颗吸收的敌弹提供多少能量。
- `_release_overload()`：过载范围与伤害。
- `UPGRADES`：14 种升级的名称和描述；`_choose_upgrade()` 等函数处理具体效果。
